# Profile: 1С:Зарплата и Управление Персоналом КОРП

## Идентификация

- `conf_doc_configuration`: ЗарплатаИУправлениеПерсоналомКОРП
- Синонимы: ЗУП, ЗУП КОРП, ZUP
- OData-публикация: `standard.odata`

## Важные особенности

- ФИО: поле `Description` у Catalog_Сотрудники и Catalog_ФизическиеЛица
- Сотрудник → физлицо: `ФизическоеЛицо_Key`
- Дата приёма: Document_ПриемНаРаботу, не Catalog_Сотрудники
- Подразделение в OData может быть `Подразделение_Key` или `ПодразделениеОрганизации_Key` — сверять с $metadata

## Decision trees

### Сотрудники (ФИО, должность, подразделение)

- Primary: `InformationRegister_КадроваяИсторияСотрудников` / SliceLast()
- conf-doc query: `КадроваяИсторияСотрудников`, `Сотрудники`
- Fallback: `InformationRegister_КадроваяИсторияСотрудников_RecordType` + orderby Period desc

### Отпуска (оформление, кто в отпуске)

- Primary: `Document_Отпуск`
- Filter: `ДатаНачала`, `ДатаОкончания`
- conf-doc query: `отпуск`, `Document.Отпуск`

### Остатки отпусков (сколько дней осталось)

- **Модель:** остаток = накоплено − израсходовано
- **Primary (готовый остаток):** `InformationRegister_АналитикаОстатковОтпусков` — поле `ОстатокДней`
- Secondary (расход): `AccumulationRegister_ФактическиеОтпуска/Turnovers()` — `КоличествоTurnover`
- Secondary (ввод): `InformationRegister_НачальныеОстаткиОтпусков_RecordType`
- conf-doc query: `АналитикаОстатковОтпусков`, `остатки отпусков`, `ФактическиеОтпуска`, `ОстаткиОтпусков`
- Drill-down Report `ОстаткиОтпусков` → чанки «Запрос СКД»

### Начисления зарплаты

- Primary: `Document_НачислениеЗарплаты`, ведомости на выплату
- conf-doc query: `НачислениеЗарплаты`, `начисление зарплаты`, `ВедомостьНаВыплатуЗарплатыВБанк`

### Увольнения

- Primary: `Document_Увольнение`
- conf-doc query: `увольнение`, `Увольнение`

## Anti-patterns

| Объект / метод | Проблема | Альтернатива |
|---|---|---|
| `InformationRegister_ОстаткиОтпусков` | Нет в OData (404) | `InformationRegister_АналитикаОстатковОтпусков` |
| `Document_Отпуск` для остатков | Документ расхода, не таблица остатков | `InformationRegister_АналитикаОстатковОтпусков` |
| `AccumulationRegister_ФактическиеОтпуска/Balance()` | Часто не опубликован (400) | `/Turnovers()` или `_RecordType` |
| IR `_RecordType` для АналитикаОстатковОтпусков | 404 | Запрос к **шапке** IR |
| `ВидОтпуска_Key` без проверки | Может не совпадать с OData | `ВидЕжегодногоОтпуска_Key` |
| Выдуманное `КоличествоBalance` | Нет такого поля | Поле из $metadata VT |

## Типовые OData-паттерны (для OData-агента)

### Сотрудники с должностью
- Entity: `InformationRegister_КадроваяИсторияСотрудников/SliceLast()`
- Expand: `Сотрудник,Должность` + nav подразделения

### Остаток отпуска
- Entity: `InformationRegister_АналитикаОстатковОтпусков`
- Select: `Сотрудник_Key`, `ВидЕжегодногоОтпуска_Key`, `Дата`, `ОстатокДней`
- Orderby: `Дата desc`
